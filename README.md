# 情報ボックス

メモ・打合せ記録・資料を一か所に集めて、検索・共有できるWebアプリです。

- 思いついたことや気づきをすぐ記録（メモ／打合せ／資料・情報）
- 紙のメモの写真を取り込むと、**端末内で無料で文字起こし**（Tesseract.js）
- Word（.docx）・テキストファイルの取り込み
- すべての記録をまとめて検索
- **プロジェクト単位で共有**：共有リンクを開くだけで参加できる
- 自分用のメモは「自分だけ」に保存（本人以外には見えません）

## 共有のしくみ

1. Googleアカウントがあれば、誰でもログインして使えます（管理者による登録は不要）。
2. ログインした人は誰でもプロジェクトを作れます。作った人がそのプロジェクトの**オーナー**です。
3. オーナーは **共有リンク** を発行します。リンクは「編集できる」用と「閲覧のみ」用を選べます。
4. リンクを受け取った人がアプリにログインした状態で開くと、「〇〇に参加しますか？」と表示され、「参加する」を押すとそのプロジェクトが自分の画面に出ます。
5. 記録が見えるのは、参加しているプロジェクトの分と、自分の「自分だけ」の分だけです。

| 誰が | できること |
|---|---|
| オーナー（作った人） | 共有リンクの発行・無効化、メンバーの権限変更・削除、プロジェクト名の変更・削除 |
| 編集できるメンバー | 記録の追加・編集・削除 |
| 閲覧のみのメンバー | 記録を見るだけ |
| メンバー全員 | 自分でプロジェクトから抜ける |

> 共有リンクを知っている人は誰でも参加できます。送る相手に注意し、不要になったリンクは「無効にする」を押してください。
> メンバーを外したときは、同じリンクで再参加できないよう、そのリンクも無効にしてください。

## 仕組みと費用

| 役割 | 使うもの | 費用 |
|---|---|---|
| 画面（アプリ本体） | GitHub Pages | 無料 |
| ログイン | Firebase Authentication（Googleログイン） | 無料 |
| データ保存・共有 | Cloud Firestore（Sparkプラン） | 無料 |
| 写真の文字起こし | Tesseract.js（利用者の端末内で処理） | 無料 |

Firebase の無料プラン（Spark）は、クレジットカードを登録しないので課金されません。
上限（保存容量 1GiB、1日あたり読み取り5万回・書き込み2万回）に達した場合は、その日の操作が止まるだけです。
写真は1枚あたり約200KBに圧縮して保存するため、数千枚程度まで保存できます。

> この無料枠はアプリの利用者全員で共有します。URLを知っていれば誰でもログインできるので、アプリのURLは使う人にだけ伝えてください。

## セットアップ手順（20〜30分）

### 手順1　GitHubにファイルを置く

1. GitHub で新しいリポジトリを作成します（例：`infobox`）。
2. このフォルダの4つのファイルをアップロードします。
   - `index.html`
   - `firebase-config.js`
   - `firestore.rules`
   - `README.md`

> 無料の GitHub アカウントで GitHub Pages を使う場合、リポジトリは **Public（公開）** にする必要があります。
> 公開されるのはプログラムだけで、記録のデータは Firebase 側でログインとプロジェクトのメンバー登録により守られます。

### 手順2　Firebase プロジェクトを作る

1. https://console.firebase.google.com/ を開き、「プロジェクトを作成」。
   - 名前は自由（例：`infobox`）。Google アナリティクスはオフで構いません。
2. プロジェクトのトップで「ウェブ」アイコン（`</>`）を押してアプリを登録します（Firebase Hosting は不要）。
3. 表示された `firebaseConfig` の値（apiKey〜appId）を、`firebase-config.js` の該当箇所に貼り付けます。
4. 左メニュー「構築」→「Authentication」→「始める」→「ログイン方法」で **Google** を有効にします。
5. 左メニュー「構築」→「Firestore Database」→「データベースを作成」。
   - ロケーションは `asia-northeast1（東京）` または `asia-northeast2（大阪）`。
   - 「本番環境モード」で開始します。

### 手順3　データの保護ルールを設定する

Firebase コンソールの「Firestore Database」→「ルール」タブに、`firestore.rules` の中身をすべて貼り付けて「公開」を押します（書き換えは不要です）。

### 手順4　GitHub Pages を公開して、URLを Firebase に登録する

1. GitHub のリポジトリで「Settings」→「Pages」を開きます。
2. 「Branch」で `main` と `/(root)` を選んで「Save」。数分で URL が表示されます。
   - 例：`https://ユーザー名.github.io/infobox/`
3. Firebase コンソールの「Authentication」→「設定」→「承認済みドメイン」に、`ユーザー名.github.io` を追加します。

### 手順5　使い始める

1. 公開された URL を開き、「Googleでログイン」します。
2. 左上の「＋ 新しいプロジェクト」でプロジェクトを作ります（例：`A社 研修導入`）。
3. プロジェクト画面の右上にある「共有」ボタンを押し、「編集できるリンクを発行」または「閲覧のみのリンクを発行」を押します。リンクがコピーされます。
4. そのリンクをメールやLINEで相手に送ります。相手はリンクを開いてGoogleでログインし、「参加する」を押せば完了です。

記録は、プロジェクト画面の「＋ 記録を追加」「写真から読み取り」「ファイル取込」から入れます。左の検索窓では、参加しているすべてのプロジェクトと「自分だけ」の記録をまとめて検索できます。

## よくある質問

**リンクを開いたら「このリンクは使えません」と出る**
オーナーがリンクを無効にしたか、URLが途中で切れている可能性があります。オーナーに新しいリンクを発行してもらってください。

**参加したのにプロジェクトが見えない**
ページを再読み込みしてください。それでも見えない場合は、オーナーにメンバーから外されていないか確認してください。

**プロジェクトを削除するとどうなる？**
中の記録と写真もすべて削除され、メンバー全員から見えなくなります（元に戻せません）。削除できるのはオーナーだけです。

**「このURLはまだFirebaseに登録されていません」と出る**
手順4-3の「承認済みドメイン」を追加してください。

**手書きの読み取り精度について**
文字起こしは端末内で行うため無料ですが、崩した手書きは誤読が増えます。明るい場所で、紙の真上から文字が大きく写るように撮影すると精度が上がります。読み取り結果は保存前に編集できます。

**アプリ名を変えたい**
`firebase-config.js` の `appName` を変更してください。
